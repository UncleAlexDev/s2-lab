# S2-Lab Стенд для отладки блока наземки

## 1. Назначение проекта

Замена блока наземки с датчиками давления и веса.

Отображение данных с АЦП каналов, получаемых по сети от блока ESZ7-SIU (SOC Xilinx Zynq)

## 2. s2-lab

```
S2-Lab Ver. 2.0.1 May 29 2026 (built May 29 2026 11:28:22)

```

#### Рабочие порты

Порты работы с ESZ7-SIU

* 16000 - UDP-порт приема данных по протоколу АТЛАС
* 8200  - TCP/IP порт передачи каманд на ESZ7-SIU

## Сборка проекта

1. Программа написана на Qt 5

   Конфигурация проекта управляется CMake (см. CMakeLists.txt)

   Необходимые пути, которые должны быть пррописаны в окружении ОС:
   C:\Qt-5.12.3\5.12.3\bin;C:\Qt-5.12.3-off\Tools\mingw730_64\bin

2. сборка

    2.1 Сборку можно выполнить в QtCreator

    2.2 Сборка в командной строке
```
    > mkdir build
    > cmake -G "MinGW Makefiles" -S . -B build -DCMAKE_BUILD_TYPE=Release
    > cmake --build ./build -j26 --config Release
```

```            
    $ cmake --build ./build --target clean
```
